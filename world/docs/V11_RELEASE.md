## What readers gain

Twenty-eight new bilingual records connect fourteen lives with fourteen histories of institutions, community work and cultural production. The biographies include context, constraints and consequences as well as dated milestones. They supply sixty new life steps, with representative place roles and explicit uncertainty. No new record creates a political timeline bar or territorial outline.

## Evidence and learning

The 28 new entries cite **42 distinct source URLs**, inspected as the specific text/catalogue material described in their metadata. A separate follow-up adds the primary-report OCR for the existing Samoa influenza entry. The complete validator reports 1,643 distinct cited pages across narrative and map material. A URL count is not a count of independently verified claims.

The Samoa follow-up changes source access/scope only: the current entry displays the selected 1919 commission source alongside the institutional history. The original narrative, dates, coordinates and V10 file remain unchanged. Data export retains the previous review limit. The report distinguishes Samoan and New Zealand calendar dates, recorded deaths and later estimates; OCR was not exhaustively collated against the facsimile. Its colonial judgments remain attributable statements.

Twelve existing regional paths gain entries. Fifteen bilingual questions ask readers to compare each new biography with its contextual record and identify what a source supports or leaves unresolved. All 32 regional path IDs and prior stops survive; combined with the other guides, the atlas retains 55 paths. These exercises have not yet been evaluated with learners.

Research ledgers map inspected sources to dated claims and document failures and conflicts:

These are original bilingual syntheses and bounded editorial checks. They do not constitute independent regional/translation specialist acceptance, full verification of inherited material, an assessment of policy effectiveness, annual borders or reconstructed journeys. Most new material concerns early modern and modern histories; ancient and medieval depth outside China remains a substantial priority.

## Local development improvements

The repository now provides a loopback preview server with a larger request queue, replacing the stock Python command that dropped some concurrent requests on this Mac. This is a verified local preview workaround; the exact socket-level cause was not proved. The compatible test-isolation flag restores the documented Node 22 workflow. Application exports and API version now follow the shared manifest. No new runtime dependency or remote service is introduced.
